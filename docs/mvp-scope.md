# MVP 范围定义

## In Scope（本轮）
- 三端工程骨架与可运行基础框架。
- 核心页面路由、后端模块、数据库实体与 API 契约。
- Mock 数据与规则引擎草案，支撑端到端演示。

## Out of Scope（后续）
- 医疗级诊断结论。
- 实时音频采集与模型推理（仅预留接口字段）。
- 第三方地图实时数据接入（仅 mock + adapter 占位）。
- 支付与会员完整闭环（仅预留字段）。

## 验收标准（MVP）
- 可完成“看风险→检测→训练→症状→报告”演示流程。
- API 契约与数据模型一致，前后端可按 mock 数据联调。
- 管理后台可看到用户、档案、规则、模板、报表占位页。
