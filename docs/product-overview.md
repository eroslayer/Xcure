# 产品概述（儿童鼻炎康复 App MVP）

## 1. 产品定位
面向 3–18 岁儿童/青少年家庭的鼻炎日常管理与数字康复产品，核心服务对象为家长/监护人。

## 2. MVP 核心闭环
1. 看风险（个性化过敏源地图）
2. 做检测（鼻健康检测，聚焦睡眠通气）
3. 开始训练（AI 康复训练计划）
4. 记录症状（每日/每周打卡）
5. 查看趋势（报告与改善趋势）

## 3. 核心能力模块
- 个性化过敏源地图：结合城市、空气质量、花粉指数、温湿度和历史敏感标签输出风险。
- 鼻健康检测：问卷化检测 + 规则引擎输出睡眠通气风险级别。
- AI 康复训练：按年龄、夜间症状和完成率动态调节训练时长与难度。
- 症状记录与报告：结构化记录鼻塞、打鼾、张口呼吸、晨起状态，生成周报/月报趋势。

## 4. 角色与权限（MVP）
- 家长端用户：注册登录、管理儿童档案、检测、训练、症状记录、查看报告。
- 管理后台用户：运营/内容/规则配置，不包含医生工作台。

## 5. 非功能目标（MVP）
- 安全：JWT 鉴权、基础 RBAC、敏感数据最小化。
- 可扩展：预留真实地图 API、音频检测、会员体系字段。
- 可观测：关键行为日志（检测提交、训练完成、症状记录）。
